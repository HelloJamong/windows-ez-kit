# Disk Tree - 폴더 트리 분석

지정한 폴더의 하위 구조를 트리 형태로 시각화하고, 각 파일과 폴더의 크기를 표시하는 분석 도구입니다.

## 주요 기능

- 폴더 하위 전체를 `├──`, `└──`, `│` 문자로 트리 구조 시각화
- 각 파일의 이름과 크기 표시 (B / KB / MB / GB 자동 단위)
- 각 폴더의 하위 전체 합산 크기 표시
- 최대 탐색 깊이 지정 가능 (기본: 무제한)
- 분석 결과를 TXT 파일로 자동 저장 (`_disk_tree_report\report_YYYYMMDD_HHMMSS.txt`)
- 접근 권한 없는 폴더는 스킵 후 경고 표시

## 사용 방법

```powershell
# PowerShell 콘솔에서 실행
.\main.ps1

# 실행 정책 오류 시
powershell -ExecutionPolicy Bypass -File ".\main.ps1"
```

1. 분석할 폴더 경로를 입력합니다. (예: `C:\Users\admin\Downloads`)
2. 최대 깊이를 입력합니다. Enter 시 무제한으로 전체 탐색합니다.
3. 콘솔에 트리가 출력되며, `_disk_tree_report\` 폴더에 TXT 보고서가 저장됩니다.

## 보고서 저장 위치

분석 결과는 분석 대상 폴더 안에 TXT 파일로 저장됩니다.

```
<분석 대상 폴더>\
└── _disk_tree_report\
    ├── report_20260518_143000.txt
    └── report_20260518_150500.txt   ← 실행할 때마다 새 파일 생성
```

`_disk_tree_report` 폴더는 트리 분석과 크기 집계에서 자동으로 제외됩니다.

## 주의사항

- 읽기 전용 분석 도구입니다. 파일을 이동하거나 변경하지 않습니다.
- 숨김 파일과 폴더도 분석에 포함됩니다.
- 접근 권한이 없는 폴더는 건너뛰고 `⚠ 액세스 거부` 경고를 표시합니다.
- 파일·폴더 정렬은 이름 오름차순(알파벳/유니코드)입니다. 같은 수준에서 폴더가 파일보다 먼저 표시됩니다.
- 파일 수가 매우 많은 폴더(수만 개 이상)는 분석에 시간이 걸릴 수 있습니다.

## 지원 환경

- Windows 10 / 11
- Windows Server 2019 / 2022
- PowerShell 5.1 이상
