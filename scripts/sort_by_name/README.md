# Sort by Name - 파일 이름순 정리

배치 파일이 위치한 폴더의 파일을 이름순으로 정렬하여 `접두사_001` 형식으로 일괄 변경하는 스크립트입니다.

## 주요 기능

- 실행 폴더 내 파일을 이름 오름차순으로 정렬
- 사용자 지정 접두사 입력 후 `접두사_001`, `접두사_002` 형식으로 일괄 변경
- 원본 확장자 유지
- 실행 전 미리보기 제공 및 사용자 확인
- 복원 스크립트 자동 생성 (`_sort_backup\restore_*.bat`)

## 사용 방법

1. `main.bat`을 정리할 폴더에 복사합니다.
2. `main.bat`을 실행합니다.
3. 접두사를 입력합니다.
4. 미리보기를 확인한 후 `Y`를 입력하면 변경이 적용됩니다.

```
======================================================================
       Sort by Name - 파일 이름순 정리
======================================================================

  대상 경로: C:\Photos\

  접두사를 입력하세요 (예: 정리용): 여행사진

  [미리보기] 다음과 같이 파일이 변경됩니다:

    DSC_0010.jpg -> 여행사진_001.jpg
    DSC_0011.jpg -> 여행사진_002.jpg
    IMG_2034.jpg -> 여행사진_003.jpg

  총 3개 파일을 정리합니다.

  계속하시겠습니까? (Y/N): Y
```

## 사용 예시

### 변경 전

```
C:\Photos\
├── DSC_0010.jpg
├── DSC_0011.jpg
├── IMG_2034.jpg
└── main.bat
```

### 변경 후

```
C:\Photos\
├── 여행사진_001.jpg
├── 여행사진_002.jpg
├── 여행사진_003.jpg
├── _sort_backup\
│   └── restore_12345_23456_3456.bat
└── main.bat
```

## 복원 방법

변경 후 `_sort_backup\restore_*.bat` 파일을 실행하면 원본 파일명으로 복원됩니다.

## 주의사항

- 스크립트 자신(`main.bat`)은 변경 대상에서 제외됩니다.
- 하위 폴더는 변경 대상에서 제외됩니다 (파일만 처리).
- 파일 이름 정렬은 알파벳/유니코드 오름차순 기준입니다.
- 파일명에 `!`, `%`, `^` 등 특수문자가 포함된 경우 정상 동작을 보장하지 않습니다.
- 스크립트를 두 번 실행하면 이전에 변경된 파일명을 기준으로 다시 정렬됩니다.
- Windows `cmd.exe` 코드페이지/파서 문제를 피하기 위해 `main.bat` 내부 안내 문구는 영문(ASCII)으로 표시됩니다.

## 문제 해결

### 실행하자마자 창이 닫히는 경우

최신 `main.bat`은 초기 오류가 발생해도 오류 메시지를 확인할 수 있도록 창을 유지합니다.
그래도 창이 즉시 닫히면 이전에 다운로드/복사한 구버전 파일일 가능성이 있으므로 최신 `main.bat`을 다시 복사해 실행하세요.
관리자 권한은 일반 폴더의 파일명을 바꾸는 데 필요하지 않습니다. 다만 `C:\Windows`, `Program Files`처럼 보호된 폴더 안의 파일을 정리할 때만 관리자 권한이 필요할 수 있습니다.
폴더 경로에 `(`, `)` 같은 괄호가 포함되어도 실행되도록 처리되어 있습니다.

## 지원 환경

- Windows 10 / 11
- Windows Server 2019 / 2022
- PowerShell이 필요하지 않습니다.
